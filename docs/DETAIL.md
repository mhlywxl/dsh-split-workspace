## Session menu entries

Every supported DSH build opens the session menu from a conversation row's **⋯** button. DSH 0.2.1 and older have no session right-click menu: the menu lists the four actions as flat rows — **Add to split / Leave split**, **Enter floating window / Exit floating window**, **Enter independent window / Exit independent window**, and **Enter system window / Exit system window** — after the stock rows, after a hairline separator, with no **Split plugin** header.

On DSH 0.2.2+ the `⋯` button and right-click open the same menu, where those four actions sit in its **Split plugin** submenu instead of as extra flat rows, so each action appears once; every row reads **Enter …** or **Exit …** according to the live state. See the [README](../README.md) for the rest.
