## 会话菜单入口

所有支持的 DSH 版本都从侧栏每行会话的「⋯」按钮打开会话菜单。0.2.1 及更早没有会话右键菜单，菜单里直接列出四个扁平条目：**加入分屏 / 退出分屏**、**进入浮窗 / 退出浮窗**、**进入独立窗口 / 退出独立窗口**、**进入系统窗口 / 退出系统窗口**；它们排在原生条目之后，以一条分隔线分组，没有「分屏插件」分组标题。

0.2.2+ 的「⋯」和右键打开同一个菜单，这四项收在「分屏插件」子菜单里，不再额外显示扁平条目，同一个菜单里每项只出现一次；每个条目按当前状态显示“进入”或“退出”。其余用法见 [README](../README.md)。
